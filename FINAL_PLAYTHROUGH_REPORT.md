## Найденные ошибки и исправления

Новых игровых дефектов, требующих изменения рабочего кода, в выполненных маршрутах не обнаружено. Уже существовавшие в ветке исправления сохранены и проверены полным набором; их происхождение не приписывается этому прогону. Описание прежних исправлений: [STUDENT_FEEDBACK_FIXES_2026.md](STUDENT_FEEDBACK_FIXES_2026.md).

Первый сетевой запуск внутри ограниченного окружения не смог подключиться к локальному серверу (EACCES). Последующие браузерные проверки выполнены с разрешённым доступом к localhost; это ограничение окружения не учитывается как игровой дефект.

Найдена воспроизводимая нестабильность `tests/student-feedback-ui.cjs`: после закрытия помощи и нового KeyD тест читал `moving` через фиксированные 150 мс, иногда раньше первого игрового RAF-кадра. Два исходных запуска завершились FAIL. Диагностика показала ready=true, blocked=false, нажатый KeyD и previousTimestamp=null. Минимальное исправление — ожидать `moving` через waitForFunction. Проверка не ослаблена: по-прежнему требуется реальное движение. После изменения отдельный набор прошёл дважды и прошёл внутри полного npm test. Новый сквозной сценарий также проверяет восстановление движения через настоящие элементы управления.

При подготовке отдельного E2E-сценария были ошибки тестового кода; эти запуски не считаются финальным PASS:

- `2026-10-19T14-33-45-255Z`: locator.uncheck: Cannot uncheck radio button. Radio buttons can only be unchecked by selecting another radio button in the same group.; место проверки — глава 1.
- `2026-10-19T14-34-33-552Z`: onScreen is not a function; место проверки — глава 2.
- `2026-10-19T14-35-19-882Z`: Expected values to be strictly equal:; место проверки — итоговая сверка SQLite.

Причины устранены в тесте: uncheck применяется только к checkbox, передан обработчик записи объяснений, ожидаются все 16 результатов с вводной главой. В последнем из этих запусков игровые главы 0–15 были завершены, но сам запуск оставлен FAIL из-за ошибочного ожидания количества строк. Финальный новый студент прошёл исправленный сценарий с нуля; прежние артефакты сохранены.
