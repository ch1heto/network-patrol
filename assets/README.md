# Анимации персонажа

Исходные `idle.mp4` и `run right.mp4` (1280×720, 10.005 с) использовались для подготовки атласов и удалены перед публикацией. Игра загружает только готовые WebP-атласы и animations.json.
В предыдущем прототипе извлечены PNG-кадры с частотой 12 кадров/с; серый фон
удалён маской нейтральных цветов и заливкой от внешнего края, края сглажены,
светлые детали и небольшая тень сохранены. Общая обрезка кадра — 250×333.

WebP-атласы с прозрачностью:
- idle.webp: 120 кадров, 12×10.
- run.webp: 108 кадров, 12×9; стартовая секунда стоящего персонажа пропущена.
- animations.json: размеры и метаданные.

В текущем расширении все три файла оставлены побайтно прежними. Повторная
обработка видео не потребовалась. Один canvas и два заранее декодированных
атласа исключают пустой кадр при переключении. RUN LEFT использует run.webp
и CSS scaleX(-1) на внутреннем canvas; внешний контейнер отвечает за движение.

Позиция — центр стоп. Масштаб 0.75–1 по глубине, z-index 100+round(Y).
WASD/стрелки и D-pad, нормализованная диагональ, скорость 210 мировых px/с
через RAF/deltaTime. Теперь сцены 2500–3000×1250–1500 и отдельная камера;
геометрия пола задаётся данными локации, сохраняется при resize.

Мебель/оборудование рисуются собственным CSS, NPC — прозрачные WebP. Новых внешних
растровых ресурсов и библиотек нет. Описание запуска, архитектуры и проверок
находится в корневом README.md. DEBUG в game.js по умолчанию выключен.

## NPC после визуальной полировки

Пять прозрачных спрайтов находятся в npcs/. Главный герой и его метаданные
не изменены. Формат, происхождение ассетов и промпты описаны в npcs/README.md.
