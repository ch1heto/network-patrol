# NPC — единый стиль персонажей

Пять прозрачных lossless WebP: alexey, dispatcher, director, teacher-anna,
teacher-sergey. Созданы встроенным image_gen.imagegen по первому кадру
существующего idle-атласа; главный герой не изменён. Полный набор промптов
в prompts.json: итоговый prompt = prefix + subjects[id] + suffix.

Одинаковое направление: semi-chibi, тонкий тёмный контур, мягкое затенение,
приглушённая палитра колледжа, детализированная одежда и обувь. Альфа-канал
сохранён. При подготовке убраны прозрачные поля и все изображения помещены
в кадр 500×666 с высотой фигуры 610 px и стопами на Y=640. Масштабирование
пропорциональное; исходная форма и цвета не ретушировались.

В мире используются полные фигуры с тем же масштабом по Y, что и герой.
В диалогах показывается верхняя часть того же изображения; у преподавателей
две разные фигуры. Дополнительные портретные копии не нужны. Тень под ногами
рисуется CSS, свет/тень в самом спрайте остаются общими с художественным стилем.

NPC пока статичные, с очень небольшим idle-покачиванием. Направленные
walk/run-анимации NPC не добавлены. Финальные пути перечислены в manifest.json.

Архивный ассет прежней итерации – Ирина, администратор серверной: отдельный прозрачный PNG, создан встроенным image_gen.imagegen по спрайту Сергея как образцу стиля. Исходный кадр 1086×1448 сохранён без редактирования; пропорции при отображении сохраняет object-fit: contain. Промпт: administrator-irina.prompt.txt. Сергей теперь сетевой техник лаборатории, Прежняя Анна использована как Ирина Викторовна – преподаватель компьютерного класса. Алексей остаётся только в IT-кабинете.

Текущий курс: Ирина Викторовна использует teacher-anna.webp. Дмитрий и Ольга Сергеевна имеют собственные administrator-dmitry.png и teacher-olga.png, созданные встроенным image_gen.imagegen по спрайту Сергея как образцу стиля. PNG и альфа сохранены без редактирования. Точные размеры и промпты перечислены в manifest.json и *.prompt.txt. Фигуры отличаются; отдельные портретные копии не создаются.
